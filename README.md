# Nigeria Malaria Data Analysis

## Project Overview
This project analyzes malaria prevalence across Nigerian states to identify high-risk regions and contributing factors.

## Objectives
- Analyze malaria cases by state and region
- Examine relationship with water sources and wealth index
- Support public health decision-making

## Tools Used
- Excel
- Power BI
- SQL

## Key Insights
- Higher malaria prevalence in rural areas
- Poor water sources increase malaria risk
- Lower wealth index correlates with higher infection rates

## Policy Recommendations
- Improve access to clean water
- Strengthen malaria prevention in high-risk states
- Increase public health awareness campaigns
